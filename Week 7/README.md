# 猜數字遊戲 (Guessing Game)

簡短說明：電腦會隨機產生 1 到 100 的整數，玩家重複輸入猜測，程式回應「太大」、「太小」，猜中時顯示總共猜了幾次。

- 程式檔案：[Week 7/guess.py](Week%207/guess.py)
- Python 版本：任一支援 `input()` 與 f-string 的 Python 3

使用方法：在專案根目錄或該資料夾開啟終端後執行：

```bash
python "d:\2026python\Week 7\guess.py"
```

執行範例（互動式）：

- 輸入 `50` → 顯示 `太大`
- 輸入 `25` → 顯示 `太大`
- 輸入 `12` → 顯示 `太小`
- 輸入 `6`  → 顯示 `太小`

程式檔案內容核心片段已包含輸入驗證與嘗試次數計數，確保非整數輸入不會造成崩潰。
